# Diagramas UML

Para visualizar los diagramas PlantUML (.puml):

1. Abre [plantuml.com/plantuml](https://www.plantuml.com/plantuml)
2. Pega el contenido del archivo `.puml`
3. Haz clic en **Submit**
4. Descarga como PNG o SVG

Alternativa: importa el archivo `.puml` en Visual Paradigm con el plugin PlantUML instalado.
